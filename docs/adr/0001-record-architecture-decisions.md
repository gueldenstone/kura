# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-31

## Context
Kura is a long-running side project worked on in bursts, partly with AI assistance. Reasons behind decisions get lost between sessions.

## Decision
We record architecture decisions as ADRs in `docs/adr/` as they are made, using the template in `docs/adr/README.md`.

## Consequences
Small overhead per decision; in return, the reasoning stays available to the owner and to future agent sessions.
